Politique de confidentialité — JOUTE
Dernière mise à jour : 8 octobre 2026
La présente politique de confidentialité explique comment l’application JOUTE traite certaines données lorsque vous utilisez ses services.
1. Responsable du traitement
JOUTE est édité par :
Marc Lassort
France
Contact : marc.lassort@gmail.com
Pour toute question relative à vos données personnelles ou à l’exercice de vos droits, vous pouvez utiliser cette adresse électronique.
2. Données susceptibles d’être traitées
JOUTE limite la collecte aux données nécessaires au fonctionnement, à la sécurité et à l’amélioration de l’application.
Selon les fonctionnalités utilisées, les catégories suivantes peuvent être traitées :
Données de compte
- identifiant technique du compte ;
- pseudonyme et informations de profil choisies dans l’application ;
- informations nécessaires à l’authentification ;
- informations transmises par un fournisseur de connexion tel que Google lorsque vous choisissez ce mode de connexion.
JOUTE n’a pas vocation à recevoir votre mot de passe Google.
Données de jeu
- progression ;
- rang ;
- Gloire ;
- XP ;
- Écus ;
- statistiques de parties ;
- résultats de matchs et duels ;
- objets et éléments de personnalisation débloqués ou équipés.
Données sociales
- relations entre joueurs ;
- demandes d’amis ;
- défis et duels ;
- messages échangés lorsque cette fonctionnalité est utilisée.
Le contenu des messages privés n’est pas envoyé aux outils d’analytics décrits ci-dessous.
Données techniques
- version de l’application ;
- numéro de build ;
- type d’environnement ;
- événements techniques liés au fonctionnement de l’application ;
- informations relatives aux erreurs et plantages ;
- informations nécessaires au diagnostic des problèmes.
Notifications
Lorsque vous activez les notifications, JOUTE peut enregistrer un identifiant technique de notification associé à votre compte afin de vous envoyer notamment :
- un nouveau défi ;
- l’information que votre tour est disponible ;
- le résultat d’un duel.
Les notifications marketing ne font pas partie du système actuellement prévu.
3. Analytics
JOUTE utilise PostHog afin de comprendre de manière limitée l’utilisation de l’application et d’améliorer l’expérience proposée.
Des événements tels que les suivants peuvent être enregistrés :
- lancement de l’application ;
- début d’une session ;
- démarrage ou fin d’une partie ;
- abandon d’une partie ;
- utilisation d’un mode de jeu ;
- succès ou échec technique de certaines fonctionnalités ;
- ouverture de certains écrans.
L’instrumentation de JOUTE est conçue pour ne pas transmettre à PostHog :
- votre mot de passe ;
- votre JWT ou autre jeton d’authentification ;
- votre code OTP ;
- le contenu de vos messages privés ;
- le texte complet des questions ;
- vos réponses libres ;
- les secrets techniques de l’application.
Un identifiant technique pseudonyme peut être utilisé afin de distinguer les sessions d’un même compte.
4. Rapports d’erreurs et de plantages
JOUTE utilise Sentry pour détecter et analyser les erreurs et plantages de l’application.
Sentry peut recevoir notamment :
- des informations techniques sur l’erreur ;
- la version de l’application ;
- le numéro du build ;
- l’environnement concerné ;
- une trace technique de l’erreur.
JOUTE configure ce service de manière à éviter volontairement l’envoi de données personnelles inutiles.
5. Hébergement et authentification
JOUTE utilise notamment Supabase pour certaines fonctions de compte, de profil, de progression et de données sociales.
Lorsque vous utilisez la connexion Google, Google traite également certaines informations conformément à ses propres règles de confidentialité.
Les fournisseurs techniques utilisés par JOUTE peuvent traiter certaines données pour le compte de l’éditeur uniquement dans la mesure nécessaire à la fourniture de leurs services.
6. Finalités
Les données sont notamment utilisées pour :
- créer et gérer votre compte ;
- sauvegarder votre progression ;
- permettre les parties et duels ;
- gérer les fonctionnalités sociales ;
- assurer la sécurité et la stabilité de l’application ;
- détecter les erreurs ;
- prévenir les abus ;
- mesurer l’utilisation générale de JOUTE ;
- améliorer l’application ;
- envoyer les notifications que vous avez activées.
7. Base juridique
Selon le traitement concerné, les données sont traitées :
- pour exécuter le service que vous demandez en utilisant JOUTE ;
- sur la base de l’intérêt légitime à assurer la sécurité, la stabilité et l’amélioration du service ;
- sur la base de votre choix ou de votre consentement lorsqu’une autorisation spécifique du système est nécessaire, par exemple pour les notifications.
8. Durée de conservation
Les données liées à votre compte sont conservées tant que votre compte JOUTE existe, sauf obligation légale ou nécessité technique particulière.
Certaines données techniques peuvent être conservées pendant une durée limitée afin d’assurer la sécurité, le diagnostic et l’amélioration du service.
Lors de la suppression de votre compte, les données rattachées au compte sont supprimées conformément au mécanisme prévu par JOUTE, sous réserve des données qu’il serait nécessaire de conserver temporairement pour des raisons légales ou de sécurité.
9. Suppression du compte
JOUTE permet de demander la suppression du compte depuis l’application.
Cette opération entraîne la suppression du compte et des données associées dans les systèmes concernés, selon les règles techniques en vigueur.
La simple déconnexion n’équivaut pas à une suppression du compte.
10. Vos droits
Conformément au Règlement général sur la protection des données (RGPD), vous pouvez notamment demander :
- l’accès à vos données ;
- leur rectification ;
- leur effacement ;
- la limitation de certains traitements ;
- l’opposition à certains traitements lorsque la loi le permet ;
- la portabilité des données lorsque celle-ci est applicable.
Vous pouvez exercer ces droits en écrivant à :
marc.lassort@gmail.com
Vous pouvez également introduire une réclamation auprès de la CNIL si vous estimez que vos droits ne sont pas respectés.
11. Notifications
Vous pouvez refuser les notifications ou les désactiver à tout moment depuis :
- les réglages de JOUTE lorsqu’ils sont disponibles ;
- les réglages système de votre téléphone.
Le refus des notifications n’empêche pas l’utilisation normale des fonctionnalités principales de JOUTE.
12. Sécurité
Des mesures techniques et organisationnelles raisonnables sont mises en œuvre afin de protéger les données et de limiter les accès non autorisés.
Aucun système informatique ne peut toutefois garantir une sécurité absolue.
13. Transferts internationaux
Certains prestataires techniques peuvent traiter des données depuis des pays situés en dehors de l’Espace économique européen.
Lorsqu’un tel transfert est applicable, il doit être effectué conformément aux mécanismes prévus par la réglementation européenne.
14. Mineurs
JOUTE n’est pas conçu pour collecter volontairement des données personnelles sensibles relatives aux mineurs.
Si des restrictions d’âge deviennent nécessaires dans le cadre de la commercialisation ou des plateformes de distribution, elles seront précisées dans l’application et dans les stores concernés.
15. Évolution de cette politique
Cette politique peut être modifiée afin de refléter l’évolution de JOUTE, de ses fonctionnalités ou de ses obligations légales.
La date de dernière mise à jour sera indiquée en haut du document.
